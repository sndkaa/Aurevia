## Fitur Utama
- Manajemen Input : Nama Pemesan, Nama Event, Kategori, Venue, dan Asuransi.
- Custom Widget : Mengimplementasikan `DatePicker` untuk pemilihan tanggal yang interaktif.
- Data Persistence : Menggunakan `SharedPreferences` untuk menyimpan data secara lokal.
- Modular UI : Menggunakan `Fragment` untuk menampilkan ringkasan data hasil input.
- Implicit Intent : Fitur membagikan detail acara ke aplikasi lain dan akses cepat ke website kampus.
- Validation : Keamanan input untuk memastikan semua data terisi sebelum diproses.
